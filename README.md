# BudgetWatchdog — Risk-Aware Savings Coach

BudgetWatchdog + Risk-Aware Savings Coach is a personal finance app that bridges the gap between **daily budgeting** and **long‑term, risk‑conscious wealth building**.

It combines:

- A **Budget Watchdog** tab for tracking everyday spending against category limits.  
- A **Risk‑Aware Savings Coach** tab for projecting savings growth under different risk profiles.

---

## 1. Problem & Motivation

Most consumer finance apps act as passive ledger books: they record transactions, but they don’t proactively warn you when you’re drifting over budget or explain how today’s choices impact future savings.

This project is built for **everyday individuals** who want:

- A clear view of where they are overspending relative to monthly budget caps.  
- A simple, risk‑aware projection of how their savings could grow over time.

---

## 2. Solution Overview

### Budget Watchdog

On the **Budget Watchdog** page you can:

- Upload or simulate a CSV ledger of transactions.  
- Set **monthly budget limits** per category (Food, Rent, Transport, etc.).  
- See an **Interactive Budget Summary**:
  - Progress bars for each category.  
  - Overspend alerts when categories are close to or over their limits.  
- Click **“Analyze with AI”** to trigger the **BudgetAnalyst agent skill**:
  - The agent aggregates your spending by category.  
  - It computes how much you’ve spent, how much of each limit is used, and flags overspent categories.  
  - It returns an **AI Budget Insight** card, a plain‑English summary calling out which categories are safe and which need attention.

### Risk-Aware Savings Coach

On the **Savings Coach** page you can:

- Adjust sliders for:
  - **Starting Capital**  
  - **Time Horizon (years)**  
  - **Risk Tolerance (Low / Medium / High)**  
- See a **Projected Portfolio Growth** chart, showing how savings could grow under different risk levels.  
- Use a pill toggle between:
  - **Plain English** — a deterministic explanation based on your inputs.  
  - **Project with AI** — which calls the **SavingsProjection agent skill**:
    - The skill maps risk level to a fixed annual rate.  
    - It runs a compound‑interest projection to produce `{ year, balance }` points.  
    - It returns an **AI‑Generated Analysis** summary describing, in plain language, what your savings could grow to over the chosen horizon.
- When AI mode is active, the analysis header changes to “AI‑Generated Analysis” and a **“Generated by AI agent”** badge appears, so users can clearly see when the explanation is agent‑powered.

## 3. Architecture

```mermaid
flowchart TD
    subgraph Frontend
        FE[Next.js Frontend] -->|Calls| APIAnalyze[API: /api/analyze-budget]
        FE -->|Calls| APIProject[API: /api/project-savings]
    end

    subgraph Backend
        BE[FastAPI (agents/main.py)] -->|Routes| Orchestrator[Orchestrator (agents/orchestrator.py)]
        Orchestrator -->|Skill| BudgetSkill[BudgetAnalyst (agents/budget_analyst.py)]
        Orchestrator -->|Skill| SavingsSkill[SavingsProjection (agents/savings_coach.py)]
    end

    APIAnalyze -->|Forwards to| BudgetSkill
    APIProject -->|Forwards to| SavingsSkill
```

This project is split into a **Next.js frontend** and a **Python ADK backend** in the `.agents` directory.

### Frontend (Next.js, `app/`)

- `app/budget/page.tsx`  
  - UI for Budget Watchdog.  
  - Manages transaction list, category limits, overspend alerts.  
  - Calls `/api/analyze-budget` and displays the AI Budget Insight card.

- `app/savings/page.tsx`  
  - UI for Risk‑Aware Savings Coach.  
  - Manages sliders, chart, and the Plain English / Project with AI toggle.  
  - Calls `/api/project-savings` and displays the AI‑Generated Analysis text plus badge.

- `app/about/page.tsx`  
  - About App page describing:
    - Target user  
    - User inputs (CSV ledger, limits, savings goal, time horizon, risk tolerance)  
    - Core outputs (budget summary, overspend alerts, risk‑aware suggestions, explanations)  
    - Why the app is useful.

- `app/api/analyze-budget/route.ts`  
  - Next.js API route that forwards requests to the Python backend’s `/analyze-budget` endpoint.

- `app/api/project-savings/route.ts`  
  - Next.js API route that forwards requests to `/project-savings` in the backend.

### Backend (Python + ADK, `.agents/`)

- `agents/main.py`  
  - FastAPI app.  
  - Exposes:
    - `POST /analyze-budget`  
    - `POST /project-savings`  
  - Calls orchestrator/skills and returns JSON to the frontend.

- `agents/orchestrator.py`  
  - Routes intents like `"analyze_budget"` to the right specialist agent function.

- `agents/budget_analyst.py`  
  - Entry point for the **BudgetAnalyst agent**.  
  - Calls `AnalyzeTransactionsSkill` and builds the AI Budget Insight response.

- `agents/tools/transactions.py`  
  - Implements `AnalyzeTransactionsSkill`:
    - Aggregates transactions by category.  
    - Computes spending vs limits, percent used, and overspend status.  
    - Returns a structured list of category stats plus a summary string.

- `agents/tools/savings.py`  
  - Implements `SavingsProjectionSkill`:
    - Accepts starting amount, years, and risk level.  
    - Maps risk level to a fixed annual rate and runs a compound‑interest loop.  
    - Returns projection points and a summary string used in the AI‑Generated Analysis.

This structure follows the **Google Antigravity + ADK** pattern, with agents and skills defined in `.agents` and exposed via a small FastAPI service.

## 4. Why Agents?

The app solves two distinct problems:

- **Short‑term budgeting** — “Where am I overspending right now?”  
- **Long‑term savings** — “How might my money grow given my risk tolerance?”

Agents fit this because they let each problem be handled by a **specialized skill**, coordinated by a simple orchestrator:

- **BudgetAnalyst agent skill** focuses on:
  - Reading transaction ledgers.  
  - Aggregating spend by category.  
  - Producing overspend alerts and an AI Budget Insight card.

- **SavingsProjection skill** focuses on:
  - Taking capital, horizon, and risk level.  
  - Running a compound‑interest projection.  
  - Producing an AI‑Generated Analysis text for the savings chart.

This gives the project:

- Clear separation of responsibilities (budget vs savings).  
- Intent‑based routing (orchestrator decides which skill to call).  
- Transparent AI explanations, where the UI clearly labels agent‑generated text and lets users toggle against the Plain English baseline.

## 5. Setup & Running the Project

### Prerequisites

- Python 3.10+  
- Node.js 18+  
- npm (or yarn/pnpm)  

### 5.0 Environment Variables

Create a `.agents/.env` file containing your Gemini API key:
```
GEMINI_API_KEY=your-gemini-api-key-here
```
This file is ignored by git (see .gitignore) and will be loaded by `load_dotenv()` in `agents/main.py`.


### 5.1 Start the agent backend

From the project root:

```bash
cd .agents
python -m venv .venv
.\.venv\Scripts\activate     # On Windows
# source .venv/bin/activate  # On macOS/Linux

pip install -r requirements.txt
uvicorn agents.main:app --host 127.0.0.1 --port 8001
```

This starts the FastAPI service exposing:

- `POST http://127.0.0.1:8001/analyze-budget`  
- `POST http://127.0.0.1:8001/project-savings`

### 5.2 Start the Next.js frontend

Open a second terminal at the project root:

```bash
npm install
npm run dev
```

Then visit:

- `http://localhost:3000/budget` for Budget Watchdog.  
- `http://localhost:3000/savings` for Risk‑Aware Savings Coach.  
- `http://localhost:3000/about` for the About App page.
